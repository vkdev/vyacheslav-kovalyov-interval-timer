# Production
В продакшне и при большой команде я бы использовал максимально гибкую многомодульную архитектуру,  и Api-impl паттерн. 

---

Многомодульная архитектура явно прописывает границы ответсвенности, ускоряет сборку проекта, способствует инкапсуляции и переиспользованию частей кода, и облегчает тестирование. При работе над проектом нескольких человек многомодульная архитектура помогает как можно реже пересекаться.

Api-Impl паттерн помогает определить публичные контракты взаимодействия с модулем и убрать реализацию внутрь, а так же снизить риск появления циклических зависимостей. Так же этот паттерн позволяет быстро менять реализацию, сохраняя публичный контракт, и повышает тестируемость.

---

## Workout Timer
Таймер управлыяет всей тренировкой, и исходя из ТЗ

```
до старта отображается исходное состояние по макету
по нажатию на Старт начинается проигрывание интервалов по порядку
активный интервал должен быть явно выделен в интерфейсе и показывать внутренний прогресс текущего интервала в соответствии с макетами
по завершении очередного интервала должен начинаться следующий
по завершении всей тренировки должно отображаться финальное состояние
пользователь должен иметь возможность поставить таймер на паузу и продолжить его
пользователь должен иметь возможность сбросить тренировку в начальное состояние
```

публичный контракт 
– создание и инициализация. на вход объект тренировки (если нет хранения данных) или id (если данные есть, и можно получить объект тренировки из БД)
– возможность наблюдателям подписываться на события таймера
– возможность принимать интенты (приостановить таймер/остановить таймер/продолжить/перезапустить)
– принимать интент с запросом состояния, и передавать наблюдателю состояние.

приватная реализация
– если есть Notification, то управлять состоянием нотификации

состояние сессии:
– workout – описание тренировки
– прошеднее время с начала тренировки
– текущее состояние idle/inProgress/paused/finished
– текущий интервал

События и интенты можно вынести в контракт, а реализацию спрятать внутрь.

```core/workout-timer/workout-timer-api(impl)```
